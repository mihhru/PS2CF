# PS2CF — Release 1.0

**[English](README.md) | [Русский](README_RU.md)**

**Игры с CompactFlash и MicroSD через штатный PC CARD-разъём ранних PlayStation 2.**

PS2CF добавляет поддержку CF-носителей в Open PS2 Loader и wLaunchELF. Проект
предназначен для ранних японских PS2 со слотом PC CARD: карту CompactFlash можно
подключить через PCMCIA → CF-переходник, а MicroSD — через дополнительный SD → CF-адаптер.
Для загрузки игр с этого носителя не нужны USB-накопитель, сетевой сервер или внешний HDD.

Release 1.0 объединяет **OPL CF v1**, **wLaunchELF CF v1**, подготовленный
установщик **Free McBoot 1.966** и готовый загрузочный образ для **PSxMemCard Gen2**.
OPL и wLaunchELF можно также запускать отдельно, если на консоли уже есть способ запуска ELF.

![CompactFlash-карты и PC CARD-переходник](images/hardware-cf-cards.jpg)

## Совместимые консоли и оборудование

| Модель | Статус |
| --- | --- |
| **SCPH-10000** | Основная тестовая консоль; проведены замеры и игровые проверки |
| **SCPH-15000** | Целевая модель со слотом PC CARD; отдельный аппаратный прогон пока не подтверждён |
| **SCPH-18000** | Целевая модель со слотом PC CARD; отдельный аппаратный прогон пока не подтверждён |

Модели с Expansion Bay вместо PC CARD и Slim-консоли не являются целевой платформой
этого CF-драйвера. Готовый образ FMCB из комплекта подготовлен для SCPH-10000,
включая загрузочные патчи для ROM 1.00J и 1.01J.

Для работы нужны:

- Совместимая PS2 со штатным слотом PC CARD.
- PC CARD / PCMCIA Type II → CompactFlash-переходник с поддержкой CF/ATA.
- CompactFlash-карта либо совместимый SD → CF-адаптер с картой SD/MicroSD.
- Способ запуска homebrew: установленный FMCB или PSxMemCard Gen2 с загрузочным образом.
- Карта памяти для сохранений: обычная PS2 MagicGate либо совместимый эмулятор карты памяти.

Проверялись настоящие CF-карты и MicroSD 64 ГБ через мост INIC-2051.
Совместимость произвольного SD → CF-адаптера не гарантируется.

## Возможности

- Запуск PS2-игр с CF и MicroSD через CF-адаптер из OPL.
- Чтение и запись **FAT32 и exFAT**.
- Цельные ISO больше 4 ГиБ на exFAT: проверен запуск образа Soulcalibur III размером 4 384 325 632 байта.
- Доступ к носителю как к **`cf:/`** в wLaunchELF: копирование файлов, создание папок, переименование и удаление.
- Ускоренное PIO-чтение с проверкой профиля и консервативным резервным режимом.
- Поддержка LBA48 при наличии соответствующей поддержки у носителя и переходника.
- **Write Operations = On** по умолчанию в OPL. Ранее сохранённая настройка Off имеет приоритет.
- Обычные обложки OPL в PNG, индивидуальные настройки игр и режимы совместимости.

В успешно проверенных играх FMV воспроизводятся плавно, без заметных торможений,
а игровой процесс — без наблюдаемых статтеров. Для части игр нужны настройки
совместимости OPL; результаты и известные ограничения приведены ниже.

Передача данных через PC CARD в этой версии использует **PIO**, а не DMA.

## Подготовка CF или MicroSD с играми

1. Подключите носитель к компьютеру. Если используете MicroSD, подготовьте её до установки в SD → CF-адаптер.
2. Используйте один основной раздел с разметкой **MBR** и файловой системой **exFAT** или **FAT32**.
   Для цельных ISO больше 4 ГиБ выбирайте exFAT. При форматировании прежние данные удаляются.
3. Создайте в корне папки `DVD` и `CD`.
4. Скопируйте ISO DVD-игр в `DVD`, а ISO CD-игр — в `CD`.
5. Безопасно извлеките носитель из компьютера и установите переходник в выключенную PS2.

Пример структуры:

```text
CF или MicroSD
├── DVD/
│   ├── Soulcalibur III (USA).iso
│   └── Game name.iso
├── CD/
│   └── CD game.iso
├── ART/
└── CFG/
```

Для первого запуска используйте **обычные несжатые `.iso`** с простыми именами.
Название не обязано содержать ID игры: OPL умеет определять его из образа.
Старый формат `SLUS_212.16.Soulcalibur III.iso` также поддерживается.
Архивы ZIP/7z/RAR нужно распаковать на компьютере. BIN/CUE не следует просто
переименовывать в ISO. Образы не нужно записывать на CF посекторно: они лежат обычными файлами.

На exFAT разбивать большие ISO не требуется. На FAT32 действует ограничение
размера одного файла — 4 ГиБ минус 1 байт; для больших игр удобнее использовать exFAT.
Если OPL сообщает о неподдерживаемой фрагментации, заново скопируйте игру
на носитель со свободным непрерывным местом, предварительно сохранив нужные данные.

## Установка на PSxMemCard Gen2

Для готового образа запускать установщик FMCB на консоли не требуется.

1. Выключите PS2 и подключите microSD **самой PSxMemCard Gen2** к компьютеру.
2. Сохраните имеющийся `MemoryCards/PS2/BOOT/BootCard-1.mcd` отдельно.
3. Скопируйте образ из `Gen2/MemoryCards/PS2/BOOT/BootCard-1.mcd` в релизном архиве по пути:

   ```text
   MemoryCards/PS2/BOOT/BootCard-1.mcd
   ```

4. Верните microSD в Gen2, установите устройство в слот 1 и выберите загрузочный
   канал 1. Включите автозагрузку BootCard, если она выключена.
5. Включите консоль и выберите **OPL CF v1**.

MicroSD с играми находится в **CF-адаптере**, а microSD с `.mcd` — в **PSxMemCard Gen2**.
Это два разных носителя с разными задачами.

Меню FMCB:

```text
Browser
System Configuration
OPL CF v1
wLaunchELF CF v1
Launch Disc
Free MCBoot Configurator
Restart System
Shutdown System
```

Оформление использует обычные текстовые символы, совместимые с ранним OSD
SCPH-10000: без служебного «мусора» вместо стрелок и заголовка.
R1 при старте FMCB запускает wLaunchELF, Start — FMCB Configurator.

![Меню FMCB; на снимке показана предрелизная сборка RC1](images/fmcb-menu.png)

## Установка на обычную MagicGate-карту 8 MB

Если FMCB уже загружается с PSxMemCard или другой карты, установите комплект на
MagicGate через подготовленный **FMCBInstaller**. Установщик привяжет загрузчик
к целевой карте; готовый `.mcd` Gen2 предназначен для Gen2.

1. Скопируйте содержимое каталога `FMCBInstaller` из релизного архива на USB-флешку FAT32. Файл `FMCBInstaller.elf`
   и папки `INSTALL` и `lang` должны находиться рядом.
2. При выключенной консоли оставьте загрузочную карту в слоте 1, а целевую
   MagicGate поставьте в слот 2. Подключите USB-флешку.
3. Загрузите существующий FMCB, откройте wLaunchELF и запустите установщик с `mass:/`.
4. Нажмите **Install**. Когда установщик предложит выбрать карту, выберите **Slot 2**
   и проверьте номер слота в подтверждении. При обнаружении только одной карты
   установщик выбирает её автоматически.
5. Выберите обычную установку для этой консоли. Для чистой установки используйте
   пустую карту; если требуется форматирование, заранее сохраните её содержимое.
6. Если установщик предложит сохранить старый конфиг FMCB, откажитесь от его
   сохранения, чтобы установить меню PS2CF.
7. После завершения выключите PS2, уберите прежнюю загрузочную карту и USB,
   переставьте MagicGate в слот 1 и проверьте самостоятельную загрузку.

## Работа с OPL и wLaunchELF

В OPL откройте список BDM-игр и выберите игру с CF. Для обновления списка используйте
**Select**. Настройки отдельной игры открываются через **Triangle**.

Чтобы включить обложки: **Start → Display Settings → Cover Art → On**, затем
сохраните настройки. PNG-файлы должны находиться в `ART` рядом с `DVD` и `CD`;
например, `ART/SLUS_212.16_COV.png` для соответствующего издания Soulcalibur III.
Наша сборка загружает PNG; простая смена расширения JPG на PNG не конвертирует картинку.

В wLaunchELF откройте **`cf:/`** для файловых операций. Запись доступна как на FAT32,
так и на exFAT. ELF-приложения в этой версии запускайте с карты памяти или USB;
непосредственный запуск ELF с `cf:/` пока не поддерживается.

## Скорость

Ориентировочные результаты замеров на SCPH-10000:

| Носитель | Последовательное чтение в RAM | Чтение файла 32 МиБ через FAT |
| --- | ---: | ---: |
| MicroSD 64 ГБ через INIC-2051 | **5,20 МБ/с** | **4,90 МБ/с** |
| CompactFlash Transcend TS16GCF133, 16 ГБ | **6,93 МБ/с** | **3,74 МБ/с** |

МБ/с здесь десятичные. Замеры получены в диагностической сборке PIO v30,
предшествовавшей интеграции в OPL: это показатели чтения, а не гарантированная
скорость каждой игры или копирования CF → USB. В файловом замере учитывалось
время чтения файла, без записи на USB. Корректность прочитанных данных проверялась
контрольными суммами. Скорость зависит от карты, моста и организации файлов.

Практический результат в совместимых проверенных играх — плавные FMV и игровой
процесс без наблюдаемых рывков. Отдельного численного бенчмарка внутри OPL пока нет.

## Проверенные игры и совместимость

На MicroSD через CF-адаптер без каких-либо проблем работали:

- Guilty Gear X2 Reload.
- Soulcalibur III.
- Need for Speed: Underground.
- Burnout 2.
- Twisted Metal: Black.
- Sonic Riders.
- Mortal Kombat: Deadly Alliance.
- Chou Aniki.

Для многих игр, зависающих во время воспроизведения FMV, срабатывает включение **Mode 1 — Accurate Reads** и **Mode 2 — Synchronous Mode**. Не включайте все режимы сразу: сохраняйте настройки для конкретной игры и начинайте повторный прогон с холодного запуска консоли.

## Ограничения Release 1.0

- **Программные VMC OPL (`VMC/*.bin` на CF/MicroSD с играми) не поддерживаются.**
  Сохранения на обычную карту памяти и на PSxMemCard Gen2 через слот карты памяти
  доступны. Gen2 сама хранит виртуальную карту в `.mcd` на собственной microSD;
  это отдельный механизм, который не требует VMC-драйвера OPL.
- Во время игры CF-драйвер работает только на чтение. Write Operations относится к операциям меню OPL.
- В специализированных CF-сборках отключена сетевая поддержка; одновременная работа
  CF с конкурирующими DEV9/HDD/SMB-драйверами не предусмотрена.
- DMA для PC CARD не используется; пункт DMA Mode в настройках игры не выбирает скорость CF.
- Полная ёмкость карт 512 ГБ и больше на реальном оборудовании ещё не проверена, так как у автора пока нет денег на MicroSD карту такого объема.
  Поддержка высоких адресов зависит и от SD → CF-моста; одного появления списка игр недостаточно.
- Форматирование CF средствами этих сборок не предусмотрено: носитель подготавливается на ПК.

## Исходные проекты и благодарности

PS2CF использует работу сообщества PS2 homebrew. Основные компоненты:

| Проект | Использование в PS2CF |
| --- | --- |
| [Open PS2 Loader](https://github.com/ps2homebrew/Open-PS2-Loader) | Основа OPL CF: меню, запуск игр, эмуляция CD/DVD и режимы совместимости |
| [wLaunchELF ISR](https://github.com/israpps/wLaunchELF_ISR) | Основа wLaunchELF CF: файловый менеджер и запуск приложений |
| [PS2SDK](https://github.com/ps2dev/ps2sdk) | Системные библиотеки, BDM и файловые компоненты |
| [FatFs, IOP-порт](https://github.com/fjtrujy/FatFs/tree/iop-r0.16) | Поддержка FAT и exFAT |
| [gsKit](https://github.com/ps2dev/gsKit) | Графические библиотеки, используемые приложениями |
| [PS2-Packer](https://github.com/ps2dev/ps2-packer) | Упаковка исполняемых ELF |
| [FreeMcBoot Installer](https://github.com/israpps/FreeMcBoot-Installer) | Установщик и исходный установочный комплект FMCB |
| [SD2PSX / sd2psXtd](https://sd2psxtd.github.io/) | Экосистема эмуляторов карт памяти и эталонные данные привязки для образа Gen2 |

Вклад PS2CF — интеграция CF-драйвера для PC CARD, ускоренные профили PIO с проверкой,
чтение и проверяемая запись, адаптация OPL и wLaunchELF, готовая конфигурация FMCB
и проверки на реальном оборудовании.

OPL, wLaunchELF и библиотеки сохраняют сведения об авторах и свои лицензии.
FMCB предоставляется готовыми загрузочными файлами из исходного дистрибутива;
наличие открытых исходников установщика не означает наличия полного исходного кода ядра FMCB.
Образ Gen2 создаётся с новой файловой системой; для привязки используются только
32 байта заголовка каждого соответствующего KELF из публичного эталона SD2PSX.
Происхождение компонентов и контрольные суммы фиксируются в манифестах сборки.

## Самостоятельная сборка

Архивы `PS2CF-1.0-source.zip` и `PS2CF-1.0-source.tar.gz` предназначены для сборки
OPL CF и wLaunchELF CF из одного и того же дерева исходников. Среда — Linux
или WSL с инструментами PS2DEV/PS2SDK; для подготовки образа карты памяти нужны Python 3
и распаковщик 7z.

Сборка OPL и современных IOP-модулей использует PS2DEV 2.0.0. EE-часть wLaunchELF
собирается в совместимой старой среде PS2DEV 1.0/1.1. Подготовка окружения и команды приведены в [BUILDING_RU.md](BUILDING_RU.md).

систему, название и ID игры, включённые Mode 1–6, используемые карты памяти и
момент сбоя. Уточните, повторяется ли он после полного выключения и включения консоли.
